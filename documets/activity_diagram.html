Activity Diagram

แผนภาพแสดงลำดับการทำงานของระบบ (Registration & Login Process)

1. Registration Process (สมัครสมาชิก)

เริ่มต้น
↓
กรอกข้อมูล Username, Password, Confirm Password
↓
SqlCleanDirective กรองอักขระพิเศษออกทันที
↓
กรอกข้อมูลครบตามเงื่อนไขหรือไม่?
↓ ไม่ครบ / ผิดเงื่อนไข
แสดงกรอบแดง + SweetAlert Warning
↓ ครบถ้วน
Password ตรงกับ Confirm Password หรือไม่?
↓ ไม่ตรงกัน
แสดง Background แดงอ่อน + SweetAlert Error
↓ ตรงกัน
ส่ง POST Request ไปยัง Go Backend
↓
Username ซ้ำในระบบหรือไม่?
↓ ซ้ำ
Backend ตอบกลับ 400 + แจ้งเตือนชื่อซ้ำ
↓ ไม่ซ้ำ
เข้ารหัส Password ด้วย Bcrypt แล้ว Save ลง PostgreSQL
↓
SweetAlert Success + Redirect ไปหน้า Login
↓
สิ้นสุด

2. Login Process (เข้าสู่ระบบ)

เริ่มต้น
↓
กรอก Username และ Password
↓
SqlCleanDirective กรองอักขระพิเศษออกทันที
↓
กรอกครบถ้วนหรือไม่?
↓ ไม่ครบ
แสดงกรอบแดง + SweetAlert Warning
↓ ครบถ้วน
ส่ง POST Request ไปยัง Go Backend
↓
Backend Query หา User ใน Database
↓
พบ User และ รหัสผ่านถูกต้องหรือไม่?
↓ ไม่ถูกต้อง / ไม่พบข้อมูล
Backend ตอบกลับ 401 + SweetAlert Error
↓ ถูกต้อง
Backend เจน JWT Token ส่งกลับมายัง Frontend
↓
บันทึก Token ลงใน localStorage
↓
SweetAlert Success + Redirect ไปหน้า Welcome
↓
สิ้นสุด

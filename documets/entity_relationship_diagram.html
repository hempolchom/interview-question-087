Entity Relationship Diagram (ERD)

ผังความสัมพันธ์ตารางข้อมูลและโครงสร้าง Database (Database Schema Architecture)

1. Entity Diagram (ตาราง users)

          erDiagram
            users {
              uint id PK "รหัสผู้ใช้งาน (Auto Increment)"
              varchar username UK "ชื่อบัญชีผู้ใช้งาน (Unique, Eng + Num)"
              text password_hash "รหัสผ่านที่ผ่านการเข้ารหัส (Bcrypt)"
              timestamptz created_at "วันเวลาที่บันทึกข้อมูล"
            }

2. Data Dictionary (รายละเอียดโครงสร้างฟิลด์ข้อมูล)

Column Name Data Type Key / Constraint Null Ability Description / Comment
id SERIAL (int4) PRIMARY KEY NOT NULL รหัสประจำตัวผู้ใช้งาน (Auto Increment Sequence)
username VARCHAR(100) UNIQUE KEY NOT NULL ชื่อบัญชีสำหรับเข้าสู่ระบบ (เฉพาะ a-z, A-Z, 0-9, _, -)
password_hash TEXT - NOT NULL รหัสผ่านที่ผ่านการเข้ารหัสความปลอดภัยด้วย Bcrypt
created_at TIMESTAMPTZ - NULL วัน เวลาที่สร้างบัญชีผู้ใช้ (บันทึกอัตโนมัติ)

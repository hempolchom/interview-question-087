UML Diagrams

แผนภาพแสดงโครงสร้างซอฟต์แวร์และสถาปัตยกรรมระบบ (System Architecture & Structural Diagrams)

1. Class Diagram (โครงสร้างระดับคลาสและโมเดล)

          classDiagram
            direction TB

            class User {
              +uint ID
              +string Username
              +string PasswordHash
              +time.Time CreatedAt
            }

            class AuthController {
              +Register(c *gin.Context)
              +Login(c *gin.Context)
              +GetProfile(c *gin.Context)
            }

            class AuthMiddleware {
              +GenerateToken(userID uint, username string) string
              +AuthMiddleware() gin.HandlerFunc
            }

            class SqlCleanDirective {
              -RegExp regex
              +onInput(event InputEvent)
            }

            class RegisterComponent {
              +FormGroup registerForm
              +boolean showPassword
              +boolean showConfirmPassword
              +boolean isSubmitted
              +onSubmit()
            }

            class LoginComponent {
              +FormGroup loginForm
              +boolean showPassword
              +boolean isSubmitted
              +onSubmit()
            }

            RegisterComponent ..> SqlCleanDirective : Uses
            LoginComponent ..> SqlCleanDirective : Uses
            RegisterComponent ..> AuthController : HTTP POST (Register)
            LoginComponent ..> AuthController : HTTP POST (Login)
            AuthController ..> User : Query / Create
            AuthController ..> AuthMiddleware : Generate Token

2. Component Diagram (สถาปัตยกรรมองค์ประกอบของระบบ)

          graph TB
            subgraph Frontend["Frontend (Angular Framework)"]
              direction TB
              RC["Register Component"]
              LC["Login Component"]
              SD["SqlClean Directive"]
              AS["Auth Service"]
              
              RC --> SD
              LC --> SD
              RC --> AS
              LC --> AS
            end

            subgraph Backend["Backend (Go Gin Framework)"]
              direction TB
              RM["Router & JWT Middleware"]
              AC["Auth Controller"]
              DBE["GORM Engine"]

              RM --> AC
              AC --> DBE
            end

            subgraph Database["Database Server"]
              PG[("PostgreSQL\n(interview_db)")]
            end

            AS -- "REST API (HTTP/JSON)" --> RM
            DBE -- "SQL Query / AutoMigrate" --> PG

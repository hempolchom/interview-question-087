API Documentation

Authentication System API Service (Go Gin / GORM / PostgreSQL)

POST /api/v1/auth/register

รายละเอียด: สมัครสมาชิกผู้ใช้งานใหม่เข้าสู่ระบบ

Request Payload (JSON)

Field Type Required Description
username String Yes ชื่อผู้ใช้งาน (a-z, A-Z, 0-9, _, -)
password String Yes รหัสผ่าน (ขั้นต่ำ 6 ตัวอักษร)
confirmPassword String Yes รหัสผ่านยืนยัน (ต้องตรงกับ password)

Response (200 OK)

{
  "success": true,
  "message": "ลงทะเบียนสำเร็จ"
}
POST /api/v1/auth/login

รายละเอียด: เข้าสู่ระบบเพื่อรับ JWT Token สำหรับการยืนยันตัวตน

Request Payload (JSON)

Field Type Required Description
username String Yes ชื่อผู้ใช้งาน
password String Yes รหัสผ่าน

Response (200 OK)

{
  "success": true,
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "username": "admin01"
  }
}
GET /api/v1/auth/profile

รายละเอียด: ดึงข้อมูลผู้ใช้งานปัจจุบัน (ต้องส่ง Authorization Bearer Token)

Headers

Header Value
Authorization Bearer <JWT_TOKEN>

Response (200 OK)

{
  "success": true,
  "data": {
    "id": 1,
    "username": "admin01",
    "created_at": "2026-09-06T13:30:00Z"
  }
}

Sequence Diagram

แผนภาพแสดงลำดับการรับส่งข้อมูลระหว่างองค์ประกอบในระบบ (Interaction Flow)

1. Registration Sequence (ขั้นตอนการสมัครสมาชิก)

          sequenceDiagram
            autonumber
            actor User as User / Client
            participant FE as Angular Frontend
            participant Dir as SqlCleanDirective
            participant BE as Go Backend (Gin)
            participant DB as PostgreSQL DB

            User->>FE: กรอก Username, Password, Confirm Password
            FE->>Dir: กรอง อักขระพิเศษ (a-z, A-Z, 0-9, _, -)
            Dir-->>FE: คืนค่า Input ที่ปลอดภัย
            User->>FE: กดปุ่ม "สมัครสมาชิก"
            
            alt ข้อมูลไม่สมบูรณ์ หรือ รหัสผ่านไม่ตรงกัน
              FE-->>User: แสดง Alert (SweetAlert2) + ไฮไลท์กรอบ/พื้นหลังสีแดง
            else ข้อมูลถูกต้องครบถ้วน
              FE->>BE: POST /api/v1/auth/register (JSON)
              BE->>DB: Query เช็ก Username ซ้ำ
              alt Username ซ้ำในระบบ
                DB-->>BE: พบข้อมูลเดิม
                BE-->>FE: 400 Bad Request (Username taken)
                FE-->>User: แสดง SweetAlert2 Error
              else Username ไม่ซ้ำ
                BE->>BE: เข้ารหัส Password ด้วย Bcrypt
                BE->>DB: INSERT INTO users (id, username, password_hash)
                DB-->>BE: บันทึกข้อมูลสำเร็จ
                BE-->>FE: 200 OK (Registration Success)
                FE-->>User: แสดง SweetAlert2 Success + Redirect ไปหน้า Login
              end
            end

2. Login Sequence (ขั้นตอนการเข้าสู่ระบบ)

          sequenceDiagram
            autonumber
            actor User as User / Client
            participant FE as Angular Frontend
            participant Dir as SqlCleanDirective
            participant BE as Go Backend (Gin)
            participant DB as PostgreSQL DB

            User->>FE: กรอก Username และ Password
            FE->>Dir: กรอง อักขระพิเศษ
            Dir-->>FE: คืนค่า Input ที่ปลอดภัย
            User->>FE: กดปุ่ม "ลงชื่อเข้าใช้งาน"

            alt ข้อมูลไม่สมบูรณ์
              FE-->>User: แสดง Alert (SweetAlert2) + ไฮไลท์กรอบสีแดง
            else ข้อมูลครบถ้วน
              FE->>BE: POST /api/v1/auth/login (JSON)
              BE->>DB: SELECT * FROM users WHERE username = ?
              alt ไม่พบ User หรือ รหัสผ่านไม่ถูกต้อง (Bcrypt Compare)
                DB-->>BE: คืนค่า ไม่พบข้อมูล / Password mismatch
                BE-->>FE: 401 Unauthorized
                FE-->>User: แสดง SweetAlert2 Error (เข้าสู่ระบบไม่สำเร็จ)
              else ข้อมูลถูกต้อง
                DB-->>BE: คืนค่า ข้อมูล User
                BE->>BE: เจน JWT Token (Secret Key)
                BE-->>FE: 200 OK (Token + User Info)
                FE->>FE: บันทึก Token ลง localStorage
                FE-->>User: แสดง SweetAlert2 Success + Redirect ไปหน้า Welcome
              end
            end
